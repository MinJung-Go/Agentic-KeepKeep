## GLM-5.3 思考参数兼容修复

- 现象：调用提示不支持关闭思考，仅支持 low / high / max。
- 根因：客户端把 GLM-5.2 的关闭与 medium 参数直接用于 GLM-5.3；原有测试也错误地锁定了这些参数。
- [x] GLM-5.3 / Flash 始终传 enabled；关闭深度思考映射 low，开启／默认映射 high，不用 max。
- [x] 根据请求最终模型名判断，兼容命名空间和大小写；旧模型保持原行为。
- [x] 设置页说明此模型关闭开关表示轻量思考。
- [x] 新增 5 项请求兼容测试，覆盖普通／流式、模型覆盖、旧模型隔离；与 10 项 wire 测试合计 15 项本地通过。
- [x] 修正 CoachSpeedTests 中原有的错误 medium／disabled 断言。
- [x] 本次修复 macOS CI 与新 IPA：0.4.6 (10)，346 XCTest 通过、0 失败。
- [ ] 实际服务端联调与真机重签安装验证。

依据：[Z.ai GLM-5.3 官方模型说明](https://huggingface.co/zai-org/GLM-5.3/blob/main/README.md) 的 low / high / max 档位，以及真机 API 返回的禁止关闭思考错误。本地测试使用拦截请求，不消耗真实 API Key。
