# 11 · 教练工具、课程表管理与外观

用户已确认本地按需查询、请求时间、可选 GLM 搜索、外观三选项，并明确要求写清单后开发。

## 功能与验收

1. 本地 SwiftData 保留所有记录，不因聊天压缩删除。教练不再默认附带 28/14 天概况；通过只读工具按日期查询健康、训练趋势、饮食和身体指标的聚合。单次范围最多 31 天，可查询历史日期；明确数据覆盖和同步时间，缺失不视为零。原文、照片、设备标识不出设备。
2. 每次实际模型请求自动注入设备当前时间（带 UTC 偏移）、本地日期、星期和 IANA 时区；重试、工具后续请求和记忆整理同样适用。隐藏于请求系统上下文，不写聊天记录或长期记忆。
3. GLM 联网搜索默认关闭，在 AI 模型设置中开启，仅智谱官方端点使用对应 Key。App 封装独立 search_std API。第一版按固定公共健身主题生成搜索词（训练、蛋白质、睡眠、有氧、减脂、恢复、拉伸），不接受模型自由文本搜索词，避免将个人数据发给搜索引擎。每轮最多 1 次搜索，最多 3 个有 HTTPS 来源的摘要；来源可点击。失败说明，不假装已搜索，不阻塞本地问答。网页为不可信资料，不能指挥工具。
4. 设置首页恢复外观选择：跟随系统（默认）、浅色、深色；即时生效并持久保存，sheet 同步。

5. AI 教练可真正修改课程表：修改主题、动作/组次/重量、训练日期、增加或删除训练日、删除整份课程表。沿用用户确认的草稿流程，固定 ID 定位，并验证课程表版本，拒绝错目标/过期操作。换动作和顺延必须修改实际字段，不能只写备注。完成后保留回执，不能重复执行。
6. 课程表首页提供删除当前课程表入口和全部课程表管理列表；删除需要确认名称，仅删除计划及其计划日/动作，不删除已有训练日志、每日记录或 Apple 健康数据。保存失败回滚并显示失败。

## 资源边界

- 每轮最多 2 次工具查询批次、每批最多 2 个查询调用；随后收回查询工具（仍可提出计划草稿），要求完成回答。计划草稿仍需确认，查询不写库。
- 查询输出有字节上限、日期范围限制、数据库条数限制；超过范围明确要求缩小，不伪装完整结果。
- 工具中间消息只在当前请求链有效，不存入聊天历史或长期记忆；最终自然语言回答按已有历史压缩策略处理。
- 工具 schema、结果、时间与协议要求保留的思考信息计入上下文预算；必要时压缩历史，保留当前问题与已验证记忆。
- 无自建服务器，不添加 MCP 服务；不开启后台 HealthKit 同步，不改变数据授权。

## 验证

单测覆盖日期/时区、工具循环与上限、取消与错误、历史结果不累积、聚合隐私边界、来源链接、搜索关闭/端点保护及外观映射。Linux 环境不能替代 Xcode CI 或真机验证；未执行的检查必须保持待验。

## 协议依据

- [智谱搜索 API](https://docs.bigmodel.cn/api-reference/工具-api/网络搜索)：使用独立 web_search 接口与 search_std。
- [智谱思考模式](https://docs.bigmodel.cn/cn/guide/capabilities/thinking-mode)：交错思考的工具后续请求保留 reasoning_content。
- [Claude extended thinking](https://platform.claude.com/docs/en/build-with-claude/extended-thinking)：工具后续请求保留 thinking/signature/redacted_thinking；这些协议数据不渲染、不持久化。

删除当前计划后，今日和课程表首页不把归档计划自动当成当前计划；归档计划仍可从管理页删除。

## 追加：移除第三方动作数据集

用户要求删除 Gym 数据集，后续 IPA 不再包含该素材。本项替代旧轮次内置动作图库的要求：移除 GIF、目录元数据、说明/肌群数据、下载与打包流程；动作详情保留课程表的名称、组次、重量与 RPE。训练记录与课程表数据不迁移、不删除。手绘样张 docs/12 保留在设计目录，不接入 App。
