### 仓库迁移（2026-09-13）

04 轮期间仓库从**私有转公开**，原因与过程记在这里，以免日后困惑：

- **起因**：私有仓库的 Actions 额度用尽（macOS runner 按 10 倍计费，约 200 分钟/月）。
  job 以「7 秒、零步骤、日志 404」失败，annotation 写着 spending limit —— **日志里看不到这句**，
  以后遇到同样现象先读 annotation。
- **障碍**：`vendor/` 里的 © Gym visual 素材与含其画面的截图，公开即等于再分发。
- **处理**：素材出库（gitignore）→ `git filter-branch` 清历史 → 发现 GitHub 仍保留悬空对象
  （旧 SHA 仍可下载）→ 删库重建（本地为干净副本）→ 公开。
- **结果**：Actions 免费不限量，CI 恢复正常。素材留在本机，设计稿照常可看，用 `vendor/fetch.sh` 可重新拉取。
