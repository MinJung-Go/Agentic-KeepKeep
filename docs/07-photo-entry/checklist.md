# 首页照片入口与一次发送修复

- 现象：首页没有明确图片入口；点发送只进入记录页，用户还得再点一次发送。
- 根因：首页只是向记录弹窗预填文字，没有提交；照片选择仅存在于记录弹窗。
- 修复：首页可选图、预览和移除，文字与照片一起准备；点发送或键盘发送立即开始解析，记录页直接展示进度与结果。纯照片可发送，选图本身不触发分析。
- 鲁棒性：读取中显示进度并禁止发送旧附件；取消任务不覆盖照片；失败保留文字与已有照片；请求消费后清空，弹窗重现不会重复提交。
- 验证：新增首页文字、纯照片和图文一次提交与防重发测试；macOS 编译通过，247 个单测全部通过。真机需复验键盘展开选图、照片替换/移除、读取失败和一次发送。
