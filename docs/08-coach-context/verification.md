# 超长上下文实现与验证

## 实现参数

| 参数 | 本轮值与语义 |
|------|--------------|
| 默认窗口假设 | 16,384；按端点 + 模型分别保存，设置中可调整，并非对服务商规格的判断 |
| App 输入上限 | 12,000 个估算单位；增加模型窗口不会突破此上限 |
| 输出预留 | 4,096；Anthropic 已有 2,048 思考预算包含在该输出额度内 |
| 安全余量 | 1,024 |
| 实际输入预算 | `min(12000, window - 4096 - 1024)`；默认 11,264 |
| 估算方式 | UTF-8 字节数 + 请求/消息/工具开销；中文、英文和工具 JSON 都计入，接口可注入替换。不是服务商 tokenizer，仍可能被实际端点判定超限 |
| 近期对话 | 目标 6 个完整轮次，预算优先；超限重试目标 1 轮，必要时可更少 |
| 历史记忆 | 含来源/日期包装最多 1,500 个估算单位；保留逐字引用及来源 SHA-256 覆盖摘要 |
| 当前计划 | 最多约 2,000 UTF-8 字节；优先匹配问题里的动作，再按临近日期选取；省略项有提示 |
| 摘要请求 | 同样检查输入预算，输出上限 2,048，不启用思考或工具 |
| 超限恢复 | 明确的上下文错误且尚无正文/思考/工具输出时，最多一次；预算缩为 65%，实际请求必须严格变小 |

短对话不调用摘要接口。长历史按完整轮次批量整理；单轮过大时分段读取原文，整轮成功后才提交记忆。缓存记录会话、覆盖水位、来源摘要和版本；新内容越界才增量整理。无 ID 的纯逻辑调用使用内容与位置生成的稳定标识。旧空回复不会发往服务商。

用户原文和工具卡片留在本地；思考过程不作为历史回传。草稿、拒绝、确认及调整结果保留历史标签和日期锚点，当前活动计划从数据库单独提供并优先于历史。历史已确认标签只表示过去发生过，不能据此推断该计划目前仍活动。

记忆使用原文引用且区分用户/助手；模型伪造引用会被拒绝。已有用户引用及匹配显式限制/纠正标记的原文行不会被模型省略。该保护不等于理解所有自然语言限制；引用过多或过长时会提示无法整理，原始消息和成功缓存继续保留。摘要失败只允许使用有效缓存加全部尚未覆盖历史且整体仍在预算内的回退。

整理与回复沿用同一取消链路；清空时使请求代次失效，阻止旧结果重新写入。新增字段均为可选值；记忆附在第一条有效聊天消息上，随聊天清空。摘要调用通过已有 UsageRecordingClient 计费用量，日志只含计数、缓存命中和耗时，无聊天/健康内容或密钥。

## 首轮性能样本

环境：GitHub `macos-latest` 的 iOS Simulator，合成中文对话，模拟客户端即时返回逐字引用。下表耗时包括首次规划及一次缓存复用，不包含实际网络请求。

| 完整轮次 | 首次摘要调用 | 缓存复用新增调用 | 最终请求估算量 | 本地耗时 |
|----------|--------------|------------------|----------------|----------|
| 10 | 1 | 0 | 10,322 | 6 ms |
| 100 | 12 | 0 | 10,322 | 74 ms |
| 500 | 62 | 0 | 10,322 | 655 ms |

另对 500 轮的预算/分轮/摘要哈希基础操作做 5 次 XCTest 测量：平均约 4 ms；测试宿主峰值物理内存平均约 68,868 kB，采样物理内存增量为 0 kB。宿主峰值不是本功能独占内存，采样增量为零不代表没有分配。

这些结果证明合成样本请求受预算约束、缓存不重复调用；不证明实际模型保留质量、首轮网络延迟或费用可接受。500 轮首次整理可能有多次串行网络调用，用户可随时停止；已完成批次持久化后可复用。真实服务商与真机复验保留在 [checklist.md](checklist.md) 的未勾选项中。本轮不打 tag、不生成 IPA。

最终 CI 复测同一合成样本：10/100/500 轮分别为 15/155/907 ms，摘要调用仍为 1/12/62 次，缓存复用新增调用为 0，请求估算量仍为 10,322。两次 runner 耗时差异表明该测量不应视为设备性能保证。
