# 记录 JSON 解析回归

## 问题与范围
用户确认 Milo 聊天可用，但记录页纯文字和图片均失败，提示 `模型返回的不是合法 JSON：invalidJSON(...)`。当前没有实际模型原始响应，不能把合成用例视为真机根因复现。

检查发现：ParserAgent 在对象解码失败后无条件尝试数组，覆盖原字段错误并重复包装；本地 JSON 检查提前拒绝完整代码围栏；格式失败没有恢复机会。

## 预期
- 按实际 JSON 顶层形态解码，保留字段路径和错误类别，不在诊断里记录照片、原文或完整响应。
- 本地接受完整 JSON 或仅包裹完整 Markdown 围栏的 JSON，仍拒绝截断、多个对象、思考和工具控制内容。
- 本地记录格式错误最多重试一次：保持原文、图片和历史，只加强输出格式要求；不使用失败输出补造记录，不切云端。
- 取消、内存警告、网络错误和空 records 不重试。失败沿用 RawNote 保存与用户确认流程。
- 无新界面。先测试复现，再实现并运行回归；Apple 构建和真机识别另列。
