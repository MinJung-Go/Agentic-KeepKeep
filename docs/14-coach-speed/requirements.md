## 搜索数量扩展与网页阅读

用户要求放开搜索结果数量，并询问网页抓取能力。

- 默认请求 10 条，Milo 可通过 count 按需请求 1–50 条，缺省为 10。
- 请求、解码、工具转交同时遵循条数设置，不能仍在旧的 3 条或 1800 字节限制处丢失结果。
- 保留有限响应体、摘要长度、URL 校验与整体上下文预算；低窗口下允许显式截断。
- 主题词与每轮一次搜索规则不变；不发出真实付费请求。
- 用户追加确认接入网页阅读：仅通过本轮搜索来源编号读取公开 HTTPS URL，不接受模型构造的任意地址。
- 每轮最多读2页，正文每页16,000字节、响应2MiB；整体上下文仍可显式截断。
- 工具流程允许本地查询→搜索→读网页→回答，最多3轮查询；阅读跟随联网总开关。
- 进度展示真实阅读开始/完成/失败/取消，正文不持久化为聊天消息。
- 同轮记录功能开发和设计稿进度，UI 仍待设计确认后开发。

依据：智谱官方网络搜索 API 的 count 范围为 1–50，默认 10。
