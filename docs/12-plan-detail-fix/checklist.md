# 课程表动作详情与误删修复

- 现象：动作详情只有名称；返回训练日后动作消失。
- 已确认：移除图库后详情缺少结构化参数与缺省文案，旧入口仍声称可看示范。
- 待真机确认的根因：List 同行混用导航与默认样式删除按钮，存在行级点击误触删除的风险；不是已证实的持久化丢失。
- 修复：单一导航行，删除移到禁止整行滑动触发的左滑菜单并确认；详情展示训练参数，编辑使用独立草稿，保存后写入。
