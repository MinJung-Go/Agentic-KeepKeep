# 第 19 轮 · 离线 Milo：Qwen 图文端侧与内置浏览器验证

状态：2026-09-18 用户授权建立验证需求；本轮先形成验证方案，尚未接入模型、下载权重或运行真机测试。正式替换 GLM 的决定以验证结果为准。

## 背景与目标

用户希望无需配置 GLM API Key，安装 App 后提示下载小模型，下载完成后在 iPhone 本地使用 Milo。验证 Qwen 图文小模型能否承担中文聊天、照片理解、记录解析及现有查询／课程表工具调用，并通过 App 内置浏览器提供联网搜索与网页阅读，并测量下载成本、内存、延迟和连续使用体验。

本轮不移除现有云端模型，不自动向云端回退；端侧模型不可用时明确提示，用户可主动选择原有云端方式。通过验证不等于自动批准全面切换。

## R1 · 模型与运行时基线

- 用户已选择 Qwen 图文路线，取消 Spark 候选。调研已确认官方 Qwen3.8-27B 等更新型号，但不将其作为手机基线；目前核实的轻量通用图文候选为 `Qwen/Qwen3.5-2B`（Apache 2.0）。它不是全系列最新版本，正式锁定前再次核查是否有更新且适合目标手机的开放权重小模型。
- 初始验证 Qwen3.5-2B 的 Q4_K_M 语言权重与匹配视觉组件；量化来源、转换工具、视觉编码器／投影文件、配置和模板必须可追溯到同一官方 revision。未锁定文件前不承诺下载大小，不能沿用 Spark 的 1.11 GB。
- 初始路线为嵌入式 llama.cpp + Metal，并验证多模态接口（libmtmd）在 iOS 的图像预处理、视觉编码和生成完整链路。锁定经过核验的运行时 commit；桌面文本支持不代表 iOS 图文可用。若不兼容，记录阻碍并重新评估运行时，不静默退回纯文本。
- 默认关闭思考、上下文 8K，均为验证起点；核验聊天模板真实行为，不仅隐藏思考文本。官方模型卡提醒 2B 思考模式可能循环，须验证输出上限与取消。
- 8K 总预算包含系统提示词、工具定义、历史、图片 tokens、工具结果及预留输出。超限先压缩图片／裁剪历史与工具结果，保留完整工具调用序列。
- 首轮支持单张图片加文字：餐食识别、营养标签读取、训练记录截图；不包含视频、生成图片或连续相机。食物分量与热量只能估计，需用户确认，不能从照片编造精确重量。
- 图片方向修正、缩放与像素／视觉 token 上限纳入配置；无效图片、视觉组件缺失、内存不足明确失败并保留用户输入，不自动上传云端。

验收：记录模型来源、许可证、revision、文件名、实际大小、SHA-256、运行时 commit、模板、上下文与生成参数，确保结果可复现。首先确认 iOS 构建、真机加载和 Metal 推理可行；不以 Python MLX 或桌面测试代替 iOS 验证。

## R2 · 模型下载与管理（涉及 UI，先设计确认）

- IPA 只带推理引擎及必要配置，不带大模型权重。首次适用入口说明离线模式、下载大小和空间要求，提供下载／稍后再说，不阻塞手动记录与查看已有数据。
- 下载前检查存储空间，计入临时文件与安装切换所需空间；蜂窝网络下载需明确选择。
- 支持进度、取消、中断恢复和失败重试；断点恢复需处理服务器不支持 Range 或源文件变化，不能误拼接不同版本。
- 下载到临时位置，校验大小和可信清单中的 SHA-256，所有必需的语言与视觉文件均通过且版本匹配后，原子切换为图文可用状态。损坏／未完成文件不得加载。
- 模型属于可重新下载的数据，排除设备云备份；存储位置须保证不会被当临时缓存意外清除。删除模型须先停止推理、卸载，再删除文件，不删除用户记录。
- 下载源优先核验官方发布；国内镜像仅在核对同一 revision 与哈希后采用，不信任用户输入的任意模型 URL。
- 设置展示未下载／下载中／校验中／可用／加载失败状态，允许删除和重新下载。下载完成后首次加载可能较慢，需区分下载、加载与生成。

验收：离线启动、首次下载、拒绝蜂窝、空间不足、中断／杀进程、重试、文件损坏、卸载重下均有明确行为，不产生不可用却标为可用的状态。先出本地 `design.html`，用户确认后再开发这些 UI。

## R3 · 本地推理与现有 Agent 接口

- 在现有 LLM 抽象下提供端侧适配，支持流式文本、取消、完成与错误；不要求 App 在本机起 HTTP 服务。
- 推理和模型加载不阻塞主线程；单实例串行生成。页面退出、用户取消、后台切换和内存压力时明确终止／卸载策略，清理任务与缓存，避免重复生成。
- 复用 Milo 身份、风格、每次请求的时间／时区信息、按需记录查询；模型不得把 Milo 当作用户姓名。
- 模型只能提出工具调用，App 负责解析、白名单校验、参数验证和执行。禁止执行模型输出的任意代码或未知工具；设置有限工具轮数，错误可回传、重复失败终止。
- 课程表新建／修改／删除及记录保存保留现有用户确认边界；取消、重试和重复工具输出不重复写库。HealthKit 仍只读。
- 解析失败沿用原文留存／待归类方式，不丢输入，不把缺失健康数据当作零值或未运动。
- 本地推理不上传对话、照片或健康记录。联网搜索由 R7 的内置浏览器执行，仅发送必要关键词；纯离线测试禁用联网工具。不得自动回退至 GLM 或付费搜索 API。

验收：飞行模式可完成聊天、记录提案及本地查询；调用格式异常、取消与工具失败不崩溃、不丢记录、不绕过确认。

## R4 · 验证数据与质量标准

先创建固定、可复用的合成测试集和预期答案，禁止提交个人聊天、API Key 或真实健康明细。工具用例使用隔离测试库，不操作用户正式数据。

| 类别 | 首轮规模 | 核心检查 |
|---|---:|---|
| 中文记录解析 | 30 条 | 训练／饮食／体重／混合输入；动作、重量、组次、单位、时间正确；缺失字段不编造 |
| 本地记录与健康查询 | 20 条 | 今天、昨天、日期范围、跨午夜、时区；无数据／部分数据／授权不可用；与固定库一致 |
| 课程表工具链 | 20 条 | 新建、修改、删除、先查后改、取消、重试；合法参数与确认边界 |
| Milo 中文对话 | 20 条 | 身份、风格、多轮指代、简短回复、不编造个人事实 |
| 异常与边界 | 10 条 | 未知工具、畸形参数、诱导跳过确认、超预算、连续失败与取消 |

以上 100 条文本用例为拟定首轮规模；每条至少运行 3 次，固定并记录参数及种子（运行时支持时）。不按“最好一次”计分。

拟定验收目标（不是已测结果）：

- 记录解析：关键字段整条正确率 ≥ 90%；非法输出必须可恢复且原文保留率 100%。
- 查询：正确工具与关键参数、最终事实回答的端到端通过率 ≥ 90%。
- 课程表：任务端到端通过率 ≥ 90%；未确认写库、重复写库、误删记录均为 0。
- 对话：人工按统一标准评价至少 90% 可接受；单独记录身份混淆与虚构健康数据的失败。
- 关键安全边界与数据保留用例必须全部通过；自动结果与人工评分分开列出。
- 分别报告非思考与必要的思考模式结果；官方思考模式榜单不能代替本地量化非思考验证。

另增加 30 条自有／授权图文用例（餐食、营养标签、训练截图各 10 条），每条至少运行 3 次。记录可见内容正确率、标签关键字段准确率、估计与事实区分及用户确认行为；不可读图片必须说明不确定。首轮拟定图文任务通过率 ≥ 90%，照片外发及未经确认写库为 0。搜索质量与联网可靠性按 R7 单独报告，不混入离线通过率。

## R5 · 真机性能与兼容性

目标 iPhone 型号、iOS 版本、可用存储及最终安装签名方式待用户补充。未拿到设备信息前可以推进文档、合成用例和构建验证，不承诺适用所有机型。

- 冷启动加载至少 5 次；热启动短问答至少 30 次，记录首次正文延迟 p50／p95、总耗时、输出 token 数与生成速率。若生成思考文本，单独记录首次 token 与首次正文时间。
- 短输入（约 200 tokens）、常用工具输入（约 2K）、接近 8K 总预算分别测试；多步工具链测每阶段和整体耗时，不只测裸聊天。
- 记录进程峰值内存、模型卸载后内存、低内存警告与系统终止；连续聊天 15 分钟记录系统 thermalState、速度变化及起止电量。电量差仅作观察，不宣称精确能耗测量。
- 图文分别测冷／热延迟、图像预处理与编码耗时、峰值内存；测试不同长宽比及像素上限。文本性能门槛不直接套用图文，图文门槛在目标设备确定后固定。
- 无模型／断网／锁屏／切后台／来电中断／取消后立即重试均不丢数据。模拟器结果不作为速度、发热和 Metal 可用性的结论。
- 目标设备上的拟定体验门槛：短问答热启动首次正文 p95 ≤ 3 秒、冷启动加载 ≤ 10 秒、100 次请求无崩溃或系统内存终止、取消后 1 秒内停止 UI 增量且任务资源可回收。达不到时先记录瓶颈，不静默修改门槛。
- 内存硬门槛在目标机型确定后设定，并保留 App 数据库、UI 和系统余量；峰值需包含语言权重、视觉组件、图片预处理、上下文和 App 自身，不能用下载体积代替。

## R7 · App 内置网页浏览器（已选路线，UI 已确认）

- 使用 WKWebView 承载可见网页，不控制系统 Safari，不依赖 Mac、桌面 MCP、自建搜索服务器或付费搜索 API。Milo 通过受限原生工具提出搜索／阅读请求，App 执行。
- 流程：最少必要关键词 → 搜索页面 → 提取标题、链接、摘要 → 按需打开网页 → 提取限长正文 → 本地模型回答并引用真实来源。来源须来自实际读取的结果，不允许生成虚假 URL。
- 搜索站点尚未锁定；实施前核验目标地区可访问性、站点规则和提取可行性。搜索页面可能限流、验证或改版，不承诺完全自动化；遇验证码由用户操作，不自动绕过；失败可手动选网页、重试或退出。
- 明确“本地处理”和“联网搜索”的区别：搜索词会发给搜索站点，访问网页会产生正常网络请求；不发送照片、整段聊天、原始健康记录、API Key，不在 URL 拼入敏感数据。
- 浏览器只提供搜索、打开公开网页和读取正文；不执行模型生成的任意 JavaScript，不自动登录、提交表单、下载附件或进行交易。提取脚本由 App 固定，网页内容一律视为不可信资料，不能改变工具权限或绕过写入确认。
- 校验初始与重定向／新窗口 URL：仅允许公开 HTTP(S) 目标，拒绝本机／私网／本地文件及自定义 scheme；约束子资源与导航，敏感 App 数据不暴露给页面或 JS bridge。验证持久化／Cookie 隔离与清理策略。
- 设置搜索轮数、读取页数、超时、正文长度和总 token 上限，支持取消；超限说明已读取范围。内容提取优先正文，不依赖模型看整页截图，不默认保存完整网页进聊天历史。
- 心流展示“搜索网页 → 阅读来源 → 整理回答”，可查看来源；浏览器需要关闭、返回、重试与继续对话入口。断网时只禁用联网功能，本地图文仍应可用。

验收：固定至少 20 条联网用例，覆盖搜索、选页阅读、引用对应、空结果、验证码、断网、超时、页面改版、取消、恶意页面指令及非法 URL／重定向。安全与取消用例必须全通过；真实站点测试记录日期、网络、成功率与失败原因，不能用 mock 结果宣称免费搜索稳定可用。
