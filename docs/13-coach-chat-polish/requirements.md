# AI 教练聊天页视觉适配

用户已确认借鉴所提供元宝截图的简洁层级，适配 KeepKeep 的 iOS 风格。

- 范围为 AI 教练聊天页，不复制品牌、图标素材或其他未实现能力。
- 系统深浅背景；中性用户气泡，普通教练回复无卡片底；计划/调整建议保留独立卡片。
- 空态标题与三个训练相关快捷问题靠近输入区，短屏/大字可滚动；点建议只填入，不自动发送。
- 顶部只保留关闭、标题、更多操作；数据使用说明收进更多，清空对话需确认。
- 底部统一圆角输入区，保留发送、收起键盘和已有停止生成入口；不增加重复停止按钮。
- 保留流式输出、历史自动定位、计划确认及应用逻辑。
- 实际执行 Xcode 构建与全量单测；视觉、键盘与动态字体的真机验证单独记录。
