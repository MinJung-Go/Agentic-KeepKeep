## 问题清单与修复方案

### 1. HealthKit 授权报错：missing com.apple.developer.healthkit entitlement

**根因**：免费 Apple ID 侧载时该 entitlement 被剥离，HealthKit 必然不可用——这是我之前在 checklist 里标注过的限制，但 App 没有把它讲清楚，只抛了原始错误。

- [x] `HealthKitService`：识别 `HKErrorMissingEntitlement`（domain `com.apple.healthkit` + code 4）与其他授权失败，转为可执行的中文说明
- [x] 区分五种状态：未请求 / 设备不支持 / 签名不支持（免费账号）/ 授权失败 / 已请求（只读）
- [x] 状态持久化：已判定不支持的安装不再反复弹原始错误，直接显示原因与影响范围
- [x] 今日页引导卡与设置页按状态给出对应文案；签名不支持时隐藏重试按钮（重试也没用）
- [x] 不因 HealthKit 失败影响其他功能（测试覆盖 classify 的全部分支）

### 2. 记录弹窗是「一次性大解析」，希望支持多轮对话

**根因**：当前是「输入 → 解析 → 确认卡片」的单轮流程，每次都要重开弹窗，没有上下文。

- [x] `ParserAgent.parse(_:history:)`：把「用户原话 + 已确认记录摘要」作为上下文
- [x] `QuickLogSheet` 改为对话流：消息流 + 底部常驻输入条，解析结果以卡片内联出现
- [x] 多轮修订可用（「再加一组」「换成 90kg」——靠 history 里的组数/重量摘要让模型理解）
- [x] 卡片保存后原地变为「已保存 N 条」，不用重开弹窗；支持清空对话
- [x] 弹窗默认全高（对话需要空间），可下拉到半屏；键盘交互式收起
- [x] 失败仍降级为 RawNote，并在失败卡片上直接给出手动记录入口

### 3. 上传图片后没有显示

**根因（两处）**：
- `PhotosPicker` 的 `loadTransferable` 失败时被我 `try?` 吞掉，整条链路静默无反应
- 照片保存后没有任何界面展示它（`MealDetailView` 没渲染 `photoData`）

- [x] 选图后立刻显示缩略图 + 「正在估算…」，可点「移除」取消
- [x] `loadTransferable` 失败明确报错，不再静默
- [x] `MealDetailView` 展示照片，点击可全屏查看
- [x] 记录流里有照片的条目显示相机徽标（用轻量 `hasPhoto` 标记，避免加载原图）
- [x] 视觉模型不支持图片时区分提示（4xx / 401 / 429 / 网络分别给不同建议）

### 4. AI 教练入口太小

- [x] 课程表页顶部常驻「和 AI 教练聊聊」大卡片；空态改为整行主按钮
- [x] 今日页无计划时给出「还没有训练计划」卡片，点击直达课程表
- [x] 保留工具栏图标入口

### 5. 对话无法渲染 Markdown（加粗等）

**根因**：`Text(String)` 不解析 Markdown（只有 `LocalizedStringKey` 才会）。

- [x] 新增 `MarkdownText`：`AttributedString(markdown:)` 解析，支持加粗/斜体/行内代码/链接，保留换行
- [x] `MarkdownFormatter` 预处理：标题标记降级、无序列表转「• 」；解析失败回退纯文本
- [x] 应用于教练消息、报告摘要与正文
- [x] 教练提示词允许适度加粗与列表，并禁用标题/表格/代码块

### 6. 界面美化与「丝滑度」

- [x] 触感反馈：保存成功、标记完成、计划入库、连接测试（统一 `Haptics` 工具）
- [x] 动画：消息插入过渡、完成状态切换（`.snappy`）、列表变更
- [x] 键盘：记录弹窗 `scrollDismissesKeyboard(.interactively)`，输入不遮挡
- [x] 记录列表支持滑动删除（HealthKit 同步项只读，不提供删除）
- [x] 今日页记录数使用 `contentTransition(.numericText())`
- [x] 录音中的麦克风按钮脉冲动效（`symbolEffect`）
- [x] 弹窗圆角与拖拽指示器、Toast 过渡
